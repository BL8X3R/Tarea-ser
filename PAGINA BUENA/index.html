¿Cómo funciona?

JavaScript escucha el botón de click, aumenta el contador y comprueba si el número alcanzado es múltiplo de 5. Cuando se cumple la condición, muestra una felicitación y el mono sonriente. El botón Reiniciar devuelve el contador a cero.

Proyecto realizado con HTML, CSS y JavaScript.
