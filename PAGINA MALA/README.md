# Reto de 5 Clicks

Versión corregida para funcionar directamente abriendo `index.html`.

## Estructura

- `index.html`
- `css/styles.css`
- `js/main.js`

## Funcionamiento

1. Cada click aumenta el contador.
2. Cada 5 clicks aparece una felicitación.
3. El botón "Reiniciar" devuelve el contador a 0.

No utiliza módulos ES (`import/export`), por lo que puedes abrir
`index.html` directamente con doble click.
